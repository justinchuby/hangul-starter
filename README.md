# 韩语字母起步站

一个无需构建步骤的单页韩语入门教学网页，面向中文初学者。它讲解韩文音节块、提供核心字母学习卡、实时拼读台、跟读检测、小测验和本地学习进度。

## 本地运行

字母学习内容可直接打开 `index.html`。不过，浏览器通常只会在 **HTTPS 或 `http://localhost`** 安全上下文中允许麦克风访问，因此要使用跟读检测，请通过本地服务器预览：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署

这是一个纯静态站点。将仓库发布到 GitHub Pages，或上传 `index.html`、`styles.css` 和 `app.js` 到任意静态托管服务即可。站点没有依赖、构建命令或服务器端配置。

## 功能

- 每张辅音、元音学习卡的正文都是可点击、可键盘激活的播放区域；底部“标为已学会”按钮独立处理进度。朗读复用浏览器中的韩语 `SpeechSynthesis` 声音，并在页面显示正在/已朗读或不支持状态
- 覆盖现代韩语全部 19 个初声和 21 个元音：10 个基础元音与 11 个组合/双元音分组呈现。像 `ㅐ / ㅔ` 的现代实际读音常接近，初学阶段先按拼写和罗马音区分
- 拼读器按“初声 + 元音 +（可选）收音”生成预组韩文音节，并以可点击、键盘可用的小按钮网格提供全部 28 个标准终声：第一组是无收音与常用单收音（含 `ㅈ`，可拼 `맞`），第二组始终可见地列出 11 个进阶复合收音。收音读法会随词变化，词末常合流为 7 类，本页先练拼写组合和听音
- `맞`（对／没错）可拼为 `ㅁ + ㅏ + ㅈ`，对应 Unicode `U+B9DE`。其拼写罗马音提示是 `maj`，但收音 `ㅈ` 通常实现为 [t] 类闭塞，所以整字可近似听作 `mat`；这不是严格音标或中文等同音
- 双收音/复合收音是特定词的固定拼写，不能任意拼叠；现代标准拼写有 `ㄳ、ㄵ、ㄶ、ㄺ、ㄻ、ㄼ、ㄽ、ㄾ、ㄿ、ㅀ、ㅄ`。词末或后接辅音时常只实现一个代表收音，后接元音时其中一个成分常会连读为下一音节初声，但都要按具体词及其形态学习。页面以 `앉다 → 앉아`、`읽다 → 읽어` 作进阶例子
- “解例的设计地图”以《训民正音解例》的设计思路摘要说明五个母形：`ㄱ`（牙音／舌根）、`ㄴ`（舌音／舌尖）、`ㅁ`（唇音）、`ㅅ`（齿音）、`ㅇ`（喉音），以及元音的天 `ㆍ`、地 `ㅡ`、人 `ㅣ` 字形逻辑；`ㆍ` 是现代标准韩语已不用的历史字母。该模块不代替系统的现代韩语语音教学
- “字形家族”展示《解例》的加画关系 `ㄱ → ㅋ`、`ㄴ → ㄷ → ㅌ`、`ㄴ → ㄹ`、`ㅁ → ㅂ → ㅍ`、`ㅅ → ㅈ → ㅊ` 和 `ㅇ → ㆆ → ㅎ`；`ㆆ` 是只用来说明 `ㅎ` 历史路径的历史字母，不在现代标准韩语中使用。加画不是“每加一笔就一定更响”的公式；`ㄲ、ㄸ、ㅃ、ㅆ、ㅉ` 是现代紧音表示，并非这条加画路线中的普通一级派生，也不按重复读处理
- 原创内联字形和声音小贴士，以手账线条插画和中文短句帮助记住常见字形与谨慎的起音联想；仅作辅助记忆，不表示精确发音规则
- 选择初声、元音与可选收音，即时生成真实的韩文音节块、罗马音和中文近似提示；由用户点击或键盘选择新项时，会自动朗读一次完整新音节（不在初次加载时播放），也可用“听发音”重播
- 辅音朗读使用 `ㅡ` 垫出的示例音（如 `ㄱ → 그`），不把孤立 jamo 冒充为唯一实际读音；元音朗读以前置无声的 `ㅇ` 组成音节（如 `ㅏ → 아`、`ㅘ → 와`），因此听到的是元音
- 浏览器内的韩语跟读检测只使用可自然朗读的完整音节（如 `가、나、다、라、마、바、사、아、자、하`，另有少量收音例子），不会要求朗读孤立 jamo。每项明确显示本次判断音节；识别会规范化 NFC、空白、常见标点与零宽字符，并检查最多 5 个最终候选中的任意一项是否包含目标音节
- 五题随机小测，逐题反馈和计分
- 进度通过浏览器 `localStorage` 保留，并可随时重置
- 若浏览器或嵌入环境禁止访问 `localStorage`，页面会自动改为仅本次会话的内存进度并说明刷新后不会保留；字母播放、拼读和小测仍可正常使用
- 手机优先、可键盘操作，包含可见焦点和屏幕阅读器状态反馈

## 跟读检测与隐私

跟读检测只会在浏览器支持 `SpeechRecognition` 或 `webkitSpeechRecognition` 时启用。点击“开始跟读”后，浏览器会请求麦克风权限，并将本次识别文字显示在当前页面中；本站不会保存、上传或持久化音频或识别文字。

不同浏览器、设备和网络对 Web Speech API 的支持不同；语音识别还可能依赖浏览器提供的在线服务，识别结果也不是绝对准确。页面会显示全部最终候选及本次依据的完整音节：例如识别到 `가.` 或 `가요` 时可宽松匹配 `가`，但不会把孤立 jamo 当作可朗读目标。若 API 不可用、页面不是 HTTPS/localhost、麦克风被拒、网络异常或没有检测到声音，页面会给出明确说明，并始终提供“听一听”、换一个易识别音节和默读替代练习。

## GitHub Pages

仓库已包含 GitHub Actions 工作流。推送到生产分支 `main` 会将仓库根目录的静态文件部署到 GitHub Pages；也可在 Actions 页面手动运行 **Deploy GitHub Pages**。预期访问地址为 <https://justinchuby.github.io/hangul-starter/>。

部署作业使用 GitHub 官方的 `github-pages` 环境。若该环境配置了部署分支限制，请在 **Settings → Environments → github-pages → Deployment branches** 中允许 `main`（或调整为项目所需策略）；否则 GitHub 会在运行任何工作流步骤前拒绝部署。
