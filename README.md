# 韩语字母起步站

一个无需构建步骤的单页韩语入门教学网页，面向中文初学者。它讲解韩文音节块、提供核心字母学习卡、实时拼读台、跟读检测、小测验和本地学习进度。

## 本地运行

字母学习内容可直接打开 `index.html`。不过，浏览器通常只会在 **HTTPS 或 `http://localhost`** 安全上下文中允许麦克风访问，因此要使用跟读检测，请通过本地服务器预览：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000>。

## 部署

这是一个纯静态站点。将仓库发布到 GitHub Pages，或上传 `index.html`、`styles.css` 和 `app.js` 到任意静态托管服务即可。站点没有依赖、构建命令或服务器端配置。

## 功能

- 每张辅音、元音学习卡都有独立的“听”按钮和“标记已学会”主区域；朗读复用浏览器中的韩语 `SpeechSynthesis` 声音，并在页面显示正在/已朗读或不支持状态
- 覆盖现代韩语全部 19 个初声和 21 个元音：10 个基础元音与 11 个组合/双元音分组呈现。像 `ㅐ / ㅔ` 的现代实际读音常接近，初学阶段先按拼写和罗马音区分
- 拼读器按“初声 + 元音 +（可选）收音”生成预组韩文音节；界面提供 `ㄱ、ㄴ、ㄷ、ㄹ、ㅁ、ㅂ、ㅇ` 七个代表收音，底层保留完整 28 个终声索引。收音读法会随词变化，本页先练拼写组合和听音
- 双收音/复合收音是特定词的固定拼写，不能任意拼叠；现代标准拼写有 `ㄳ、ㄵ、ㄶ、ㄺ、ㄻ、ㄼ、ㄽ、ㄾ、ㄿ、ㅀ、ㅄ`。词末或后接辅音时常只实现一个代表收音，后接元音时其中一个成分常会连读为下一音节初声，但都要按具体词及其形态学习。页面以 `앉다 → 앉아`、`읽다 → 읽어` 作进阶例子，并保留双收音在主拼读流程之外
- “解例的设计地图”以《训民正音解例》的设计思路摘要说明五个基本辅音的发音位置，以及元音的天 `ㆍ`、地 `ㅡ`、人 `ㅣ` 字形逻辑；`ㆍ` 是现代标准韩语已不用的历史字母。该模块不代替系统的现代韩语语音教学
- “字形家族”将 ㄱ/ㄷ/ㅂ 的加笔送气关系和 ㅅ → ㅈ → ㅊ 的笔画派生并列展示；`ㄲ、ㄸ、ㅃ、ㅆ、ㅉ` 标为现代紧音，不按普通重复读处理，也不将罗马音提示当作完整发音等式
- 原创内联字形和声音小贴士，以手账线条插画和中文短句帮助记住常见字形与谨慎的起音联想；仅作辅助记忆，不表示精确发音规则
- 选择初声、元音与可选收音，即时生成真实的韩文音节块、罗马音和中文近似提示
- 辅音朗读使用 `ㅡ` 垫出的示例音（如 `ㄱ → 그`），不把孤立 jamo 冒充为唯一实际读音；元音朗读以前置无声的 `ㅇ` 组成音节（如 `ㅏ → 아`、`ㅘ → 와`），因此听到的是元音
- 浏览器内的韩语跟读检测：显示基础音节，使用 Web Speech API 的 `ko-KR` 识别作宽松匹配，并提供不使用语音的替代练习
- 五题随机小测，逐题反馈和计分
- 进度通过浏览器 `localStorage` 保留，并可随时重置
- 手机优先、可键盘操作，包含可见焦点和屏幕阅读器状态反馈

## 跟读检测与隐私

跟读检测只会在浏览器支持 `SpeechRecognition` 或 `webkitSpeechRecognition` 时启用。点击“开始跟读”后，浏览器会请求麦克风权限，并将本次识别文字显示在当前页面中；本站不会保存、上传或持久化音频或识别文字。

不同浏览器、设备和网络对 Web Speech API 的支持不同；语音识别还可能依赖浏览器提供的在线服务，识别结果也不是绝对准确。若 API 不可用、页面不是 HTTPS/localhost、麦克风被拒、网络异常或没有检测到声音，页面会给出明确说明，并始终提供“听一听”和默读替代练习。

## GitHub Pages

仓库已包含 GitHub Actions 工作流。推送到 `justinchuby-hangul-learning-page` 分支会将仓库根目录的静态文件部署到 GitHub Pages；也可在 Actions 页面手动运行 **Deploy GitHub Pages**。预期访问地址为 <https://justinchuby.github.io/hangul-starter/>。

部署作业使用 GitHub 官方的 `github-pages` 环境。若该环境配置了部署分支限制，请在 **Settings → Environments → github-pages → Deployment branches** 中允许 `justinchuby-hangul-learning-page`（或调整为项目所需策略）；否则 GitHub 会在运行任何工作流步骤前拒绝部署。
